# Contributing

File an issue with a concrete transcript and expected behavior. For a change,
update the specification, schemas, reference implementation and relevant black-box
tests together. Run `python3 -m unittest discover -s conformance -v` from this
directory. Do not add credentials, real conversation data, generated databases,
private source, or private repository history.

Contributions are submitted under this repository's Apache-2.0 license. Maintainers
review compatibility and scope, and document material decisions publicly. A
compatible implementation may be independently named and operated; no hosted
Tincan account is required. Do not describe a test pass as comprehensive security
certification or imply endorsement through use of the Tincan brand.
